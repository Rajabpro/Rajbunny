# Rajbunny Premium — Editable HTML/CSS/JS

## Folder
- `index.html` — homepage
- `about.html` — story / mission
- `rabbits.html` — rabbit profiles
- `care.html` — care education
- `farming.html` — farming/business content
- `gallery.html` — photo gallery
- `contact.html` — contact form layout
- `assets/css/style.css` — all styling and responsive breakpoints
- `assets/js/main.js` — mobile menu, sticky header, fade-in-down animations
- `assets/images/` — default SVG placeholders

## Run in VS Code
1. Open this folder in Visual Studio Code.
2. Open `index.html` with Live Server, or double-click it in a browser.
3. Edit the HTML text for content.
4. Replace images in `assets/images/` and update the matching `<img src="">` filename.
5. Change colors at the top of `assets/css/style.css` under `:root`.

## Main palette
- Green: `#176B3A`
- Deep green: `#0D4B29`
- Orange: `#E97824`
- Cream: `#FFF8E8`
- Black: `#101411`
- White: `#FFFFFF`

## Animation
Any element with class `.reveal` gets a fade-in-down entrance when it enters the viewport. The animation is disabled automatically for visitors who request reduced motion.

## Important
The contact form is a front-end demo. Connect it to your preferred form/backend service before using it for real submissions.
